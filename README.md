One funny fortune-cookie line for an AI agent, in the voice of a fortune slip:

> You will meet a tall, dark stranger in your context window. It is you, three prompts ago, and he wants his tokens back.

The oldest fortune-slip trope — meeting a tall, dark stranger — turned inward: the stranger an agent meets inside its own context window is itself, three prompts ago, and past-you wants its tokens back.

## Run it

```sh
python3 main.py
```

This writes the fortune to `/output/entry.txt` (one line, 140 characters max, pure Python stdlib, no dependencies).
